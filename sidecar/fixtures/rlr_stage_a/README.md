# RLR Stage A synthetic fixtures

Every row in this folder is a synthetic injected test value, never a player measurement. No real
session, track, gamertag or pad identifier appears here. The files are regenerated byte-for-byte by
`FIXTURES` in `sidecar/test_qorcap_rlr_stage_a.py`, which checks that they still match.

- `no_hb_v0.jsonl`: qorcap-inputs/v0 with R2 presses and no hb rows. Continuity UNKNOWN, candidates counted, stats null.
- `empty_input.jsonl`: header, status and chunk rows only, no `in` rows.
- `multi_status_reconnect.jsonl`: a press that straddles an unplug/reconnect. No pair crosses the status boundary.
- `hb_qualified.jsonl`: healthy hb coverage with the injected brief example (dwells 200/300 ms, interval 500 ms), plus imu/haptic rows that are skipped.
- Missing file: covered in tests by pointing the tool at a folder with no inputs.jsonl (no fixture file can represent absence).
