# Lag band

PROVISIONAL. Not validated on a real practice match.

ADS zoom and ammo decrement are separate hooks. They are not pooled. OPTIONS-to-pause is not a measurement. Thirty copies of one OPTIONS probe do not meet the floor. A probe counts only with its own id and its own source frame.

The thirds are elapsed time. Each third of the span from the first sample to the last has to contain a sample. Splitting a list into three equal counts is not coverage. A set that meets the numeric floor is diagnostic. It is not a measured causal lag, so the seal window still treats lag as unavailable.

Failed and ambiguous probes are recorded. The pause crop stays `stub_not_calibrated`. The center and ammo crops are not validated on match-20261106-201029.

If measured lag is missing, or the pause-menu exit is missing, the seal
exclusion window stays unresolved and does not release later events into counts.
